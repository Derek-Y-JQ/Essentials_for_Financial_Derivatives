# Companion Python Code

This directory contains the supplementary Python scripts extracted from the main LaTeX manuscript of *Essentials for Financial Derivatives*. Keeping implementation code here separates the mathematical exposition in the textbook from runnable numerical experiments.

## Contents

- `ch01_introduction.py`: Option payoff diagrams.
- `ch02_discrete_time_models.py`: Binomial tree pricing (European & American) and CRR convergence experiments.
- `ch03_math_preliminaries.py`: Brownian motion simulation, quadratic variation, and simple-process approximation of Itô integrals.
- `ch04_black_scholes_model.py`: Black–Scholes PDE finite-difference schemes, analytical pricing/Greeks, and multi-asset Monte Carlo.
- `ch05_implied_volatility.py`: Implied volatility and smile visualization.
- `ch06_exotic_options.py`: Barrier (down-and-in) and geometric Asian option pricing scripts.
- `ch09_problem_set.py`: Starter code templates for programming exercises in the Problem Set.
